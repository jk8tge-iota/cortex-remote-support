먼저 연결을 확인하세요

  1. Quad Cortex mini에 별도로 전원을 공급하고 iPad와 USB-C 데이터 케이블로 연결하세요. 충전 전용 케이블로는 MIDI 통신을 할 수 없습니다. iPad에 따라 호환 어댑터가 필요합니다.
  2. mini에서 Settings → Device → MIDI → MIDI Over USB를 켜세요. 직접 연결할 때는 메시지 루프를 피하도록 MIDI Thru를 끄세요.
  3. 앱의 연결 화면에서 MIDI 출력과 기기에 맞는 채널을 선택하세요. 명령을 보낼 수 있는 상태는 기기의 확인 응답을 뜻하지 않습니다.
  4. 기기가 없을 때는 Demo로 둘러보세요. Demo는 실제 MIDI를 전송하지 않습니다.

iPadOS 26.0 이상이 필요합니다. USB 오디오가 작동하는 것만으로 MIDI 설정이 올바르다고 볼 수는 없습니다. 앱의 설정 → 도움말 → 연결 및 피드백 설정에서 안내를 받을 수 있습니다.

기기의 변경 사항을 앱에서 받으려면

앱에서 MIDI 입력을 선택하세요. 템포를 받으려면 mini의 MIDI Clock Out을 연결된 포트에 활성화해야 합니다. 프리셋·씬·익스프레션 피드백은 기기에 해당 MIDI Out 메시지를 할당하고 저장해야 합니다. MIDI 입력 선택만으로 모든 상태가 자동 동기화되지는 않습니다. MIDI, CC, PC 채널과 메시지 값이 앱의 매핑과 일치하는지 확인하세요.

선택한 입력, 채널과 따라가기 옵션을 확인하고 활동에서 수신 메시지를 확인하세요. 물리적인 모드 변경이나 설정하지 않은 동작은 보고되지 않을 수 있습니다.

컨트롤을 사용할 수 없을 때

출력이 연결되어 있고 앱이 활성화되어 있는지 확인하세요. 실기기 조작 시에는 Demo를 꺼야 합니다. 편집이 잠겨 있으면 상단 잠금을 1초간 길게 눌러 해제하세요. 스톰프는 의도한 모드를 적용하고 모드 슬롯 할당도 일치해야 합니다. 일부 값은 명령을 보내거나 설정된 보고를 받기 전까지 알 수 없음으로 남습니다.

이름, 배치와 즐겨찾기

연필 버튼이나 설정 → 이름에서 로컬 표시용 이름을 편집하세요. mini에 저장된 이름은 바뀌지 않습니다. 설정 → 레이아웃 및 배치에서 패널을 표시하거나 숨길 수 있고, 패널 제목을 길게 눌러 배치할 수 있습니다. 즐겨찾기는 설정에서 관리하고 패널로 표시할 수 있습니다.

컴퓨터에서 이름 편집하기

이름 편집기는 프리셋, 씬, 스톰프와 모드 이름을 브라우저에서 편집하고 JSON으로 내려받는 도구입니다. 파일은 서버로 업로드하지 않습니다. 로컬 초안에는 전체 백업과 엔드포인트 이름이 포함될 수 있으므로 공용 컴퓨터에서는 로컬 초안을 지워 주세요.

현재 편집기 파일과 이름만 가져오기는 업데이트된 앱이 필요합니다. 최초 승인된 베타에서는 이 작업 흐름을 지원하지 않습니다. 버전 3 백업은 mini 파일로, 버전 4는 기기 프로필을 명시한 파일로 처리합니다. 업데이트된 앱에서는 동일한 기기 프로필로 전환한 뒤 가져오세요.

오리지널 Quad Cortex 개발 미리보기

오리지널 Quad Cortex 프로필은 현재 Demo 전용이며 실제 MIDI 전송이 비활성화되어 있습니다. A–H와 Hybrid를 표시하지만 실기기 지원을 뜻하지 않습니다. mini용 설정과 별도로 보관됩니다.

업데이트된 앱에서는 이름만 가져오기로 충돌을 개별 검토하고 다른 설정을 유지할 수 있습니다. 전체 설정 교체를 선택하면 다른 설정도 교체되며, 빈 파일의 전체 복원은 기본 설정을 적용합니다. 프로필별 이름, 즐겨찾기, 배치와 MIDI 구성은 독립적이고 내보내기에는 활성 프로필만 포함됩니다. 편집기는 영어, 한국어, 일본어와 독일어를 지원합니다.

템포와 다른 앱에서 돌아왔을 때

중앙 BPM을 탭하면 수동 탭, 길게 누르면 목표 BPM 입력입니다. 목표값은 숫자 템포 명령이 아니라 시간 간격을 둔 CC44 탭 4회로 전송됩니다. 수신 MIDI 클록과 로컬 추정값은 구분됩니다.

앱이 비활성화되면 대기 중인 작업을 멈추고 복귀 시 취소된 명령을 재전송하지 않습니다. 최신 기기 상태가 필요하면 mini에서 피드백을 설정한 프리셋을 다시 불러오세요. 악보는 별도의 앱에서 사용합니다.

문제 해결 전 백업하기

설정 → 설정 내보내기로 JSON 백업을 저장하세요. 가져오기는 교체 전 변경 사항을 미리 보여 주며 로컬 MIDI 엔드포인트를 다시 연결해야 할 수 있습니다. 백업에는 로컬 이름과 설정이 포함되므로 필요한 경우에만 공유하세요.

문제 보고에 포함하면 좋은 내용

  • 앱 버전, iPad 모델과 iPadOS 버전
  • mini 펌웨어 버전, 케이블과 허브 구성
  • 예상한 결과, 실제 결과와 재현 단계
  • 가능하면 스크린샷이나 영상. 공유를 원치 않는 정보는 제거해 주세요.

필요하면 설정 → 고급 설정 → 진단에서 보고서를 미리 확인한 뒤 이메일로 공유하세요. 엔드포인트 이름은 기본적으로 제외됩니다. 전체 설정 백업은 꼭 필요한 경우 내용을 확인한 후에만 보내 주세요.

설정 → 빠른 튜토리얼에서 안내를 다시 볼 수 있습니다. 앱은 영어, 한국어, 일본어와 독일어를 지원합니다. 이 웹사이트의 소개·지원·개인정보 페이지는 영어와 한국어로 제공됩니다.
