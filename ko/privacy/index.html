Cortex Remote로 돌아가기

개인정보 처리방침

시행일: 2026년 9월 16일 · 한국어 번역: 2026년 9월 18일

Cortex Remote는 iPad에서 로컬로 작동합니다. 앱 계정, 광고나 개발자가 운영하는 분석 기능을 요구하지 않습니다.

정보 처리 주체

Cortex Remote는 IOTA Lab이 개발합니다. 개인정보 관련 문의나 요청은 jk8tge@iotalab.biz로 보내 주세요.

기기에 저장되는 정보

앱은 MIDI 구성, 엔드포인트 선택, 로컬 프리셋·세트리스트·씬·스톰프 이름, 즐겨찾기, 패널 배치, 언어와 기타 환경설정을 기기에 저장합니다. 설정 가져오기를 위한 로컬 복구 스냅샷도 유지합니다. MIDI 입력은 컨트롤과 제한된 활동 기록을 갱신하기 위해 로컬에서 처리합니다.

MIDI 명령은 사용자가 선택한 엔드포인트로 전송됩니다. 이는 컨트롤러의 기능이며 연주나 설정을 IOTA Lab 서버로 업로드하지 않습니다. 앱에는 광고나 제3자 분석 SDK가 없고 다른 앱이나 웹사이트에서 사용자를 추적하지 않습니다.

이름 편집기 웹사이트

이름 편집기는 선택한 JSON 파일을 브라우저에서 처리하며 서버로 업로드하지 않습니다. 이름, 설정과 엔드포인트 이름이 포함된 작업 중인 전체 백업을 해당 브라우저의 IndexedDB에 저장하고, 인터페이스 언어를 localStorage에 기억합니다. ‘로컬 초안 지우기’를 사용하거나 웹사이트 데이터를 지우면 저장된 백업을 삭제할 수 있습니다. 내려받은 파일은 사용자가 저장한 위치에 남습니다. 공용 컴퓨터에 초안을 남겨 두지 마세요. 편집기에는 분석 기능, 계정이나 제3자 스크립트가 없습니다. GitHub Pages는 아래 설명처럼 일반적인 웹사이트 요청을 수신합니다.

직접 내보내거나 공유하는 파일

설정 내보내기와 진단 공유는 사용자가 시작할 때만 실행됩니다. 설정 백업에는 로컬 이름, 즐겨찾기, 구성과 엔드포인트 이름이 포함될 수 있습니다. 공유하기 전에 확인해 주세요. 파일 및 공유 서비스는 사용자가 선택한 목적지의 정책과 방식에 따라 내보낸 정보를 처리합니다.

진단 보고서는 공유 전에 미리 볼 수 있습니다. 프리셋 이름, 전체 설정 내용, 기기 식별자, 일련번호와 시스템 가동 시간은 제외됩니다. 엔드포인트 이름은 사용자가 포함하도록 선택할 때만 들어갑니다. 진단 정보는 IOTA Lab에 자동으로 전송되지 않습니다.

지원 문의

이메일을 보내면 이메일 주소, 메시지와 첨부 파일을 받습니다. 문의에 답하고 문제를 조사하는 데 사용합니다. 이메일 제공업체는 메시지를 전달하고 보관하기 위해 이를 처리합니다. 이 정보를 판매하거나 광고에 사용하지 않습니다. 문의 처리, 관련 지원 기록 유지와 적용되는 의무 이행에 필요한 기간 동안 보관합니다. 이메일로 열람, 정정이나 삭제를 요청할 수 있으며 적용되는 법적 요건에 따라 삭제 범위가 달라질 수 있습니다.

백업과 삭제

앱을 삭제하면 해당 설치의 로컬 앱 데이터가 제거됩니다. 내보낸 파일, 이메일과 시스템 백업은 다른 곳에 남을 수 있으므로 저장된 기기나 서비스를 통해 관리하세요. 기기 백업 서비스는 시스템 설정에 따라 앱 데이터를 포함할 수 있습니다. 앱은 자체 클라우드 계정이나 동기화 서비스를 제공하지 않습니다.

Apple 및 TestFlight

Apple은 자체 정책과 사용자의 설정에 따라 설치, 충돌, 진단이나 베타 테스트 정보를 처리할 수 있습니다. TestFlight 테스트 중에는 Apple이 베타 피드백과 진단 정보를 개발자에게 제공할 수 있습니다. 앱 문제 조사와 개선을 위해 이 보고서를 사용합니다. Apple 개인정보 보호 안내를 참고해 주세요.

이 웹사이트

이 페이지들은 GitHub Pages에서 호스팅됩니다. 분석 스크립트, 추적 픽셀, 광고나 쿠키를 추가하지 않습니다. GitHub는 방문 시 IP 주소와 요청 기록 등의 기술 정보를 처리할 수 있습니다. GitHub 개인정보 처리방침을 참고해 주세요. 외부 링크나 이메일을 열면 해당 서비스의 개인정보 처리 방식이 적용됩니다.
